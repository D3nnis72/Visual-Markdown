# Priority-list writing check

Checked on 2026-11-05 with the full Visual Markdown skill and the revised
DocDriven writing guide. Five independent formulations per version used the same
four issues: partial offers blocked, wrong currency, approval missing in Compare
but available in List, and old borders. Each issue had a detail-page link.

All five versions with the old skill added a `next:` field to every item,
repeating its title, for example “Die Rahmen an das aktuelle Design anpassen.”
All five versions with the revised skill used a short title, priority, one impact
sentence and a detail link. None added a redundant `next:` field. Both versions
kept the List workaround and the distinction between functional and visual impact.

This is a wording check, not a statistical reliability claim. The renderer syntax
is unchanged; concrete pending tests and decisions can still use `next:`.
